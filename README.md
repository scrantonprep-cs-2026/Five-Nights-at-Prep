# Five Nights at Prep (FNAP)

A Five Nights at Freddy's-inspired survival game set at Scranton Prep, where players must survive increasingly difficult nights while avoiding roaming animatronics.

## How to Run

1. Install Python 3.
2. Install the required libraries: `pip install -r requirements.txt`
3. Run the project using: `python src/main.py`

## Folders

- `src/` - Main Python code and game systems
- `assets/` - Images, sounds, and other game resources
- `docs/` - Team charter, design documents, and project plans
- `spikes/` - Prototype experiments and testing
- `tests/` - Test code and quality assurance

## How We Work

### Decision-Making
- Team members pitch ideas and discuss potential concerns before making decisions.
- If an agreement cannot be reached, an outside party will be consulted, and the team will follow their recommendation.

### Communication
- Gmail is used for in-school communication.
- Snapchat, Discord, and text messaging are used for communication outside of school.
- Team members are expected to respond to questions within five hours.

### Meetings
- The team meets outside of class at least once every weekend, preferably at the library.
- Alternative meeting locations include either team member's home or a cafe.
- During meetings, team members primarily work on their assigned responsibilities while testing each other's systems and providing feedback.
- The team also typically calls every few days to collaborate, work through problems, and exchange feedback.

### Accountability
- If a team member is not meeting their responsibilities, the issue will first be addressed through a private conversation between team members.
- If the issue remains unresolved, the team will meet with the teacher to determine how to move forward.
